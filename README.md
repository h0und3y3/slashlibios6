# Slashlib iOS 6 — Objective-C port

Проект переносит Slashlib на Objective-C/UIKit для старых устройств iOS. Целевые параметры: **iOS 6.0+, ARMv7, rootful jailbreak для DEB**. Исходный проект был Swift-приложением с минимальной версией iOS 10; этот порт не является бинарно совместимой сборкой исходного Swift-кода.

## Сборка через Theos + Linux (основной вариант)

Theos официально поддерживает Linux как хост для сборки iOS-приложений. В репозитории добавлены `Makefile`, `build-theos.sh` и workflow `.github/workflows/build.yml`.

GitHub Actions использует Ubuntu 22.04, устанавливает Theos и Linux iOS toolchain, получает iPhoneOS 9.3 SDK из репозитория Theos SDKs и собирает ARMv7 с deployment target 6.0. IPA после упаковки проверяется и нормализуется до стандартного `Payload/Slashlib.app`. Один и тот же `.app` упаковывается в два формата:

- `build/Slashlib.ipa` — IPA-контейнер с `Payload/Slashlib.app`;
- `build/ru.slashlib.client_0.3.0_iphoneos-arm.deb` — rootful Debian-пакет для jailbreak-устройств.

### Запуск

1. Загрузите содержимое проекта в GitHub-репозиторий.
2. Откройте **Actions → Build Slashlib iOS 6 (Theos / Linux)**.
3. Нажмите **Run workflow** либо отправьте commit в `main`/`master`.
4. После успешного завершения скачайте artifact `Slashlib-iOS6-Theos-Linux`.

При создании тега `v*` workflow также прикрепит оба пакета к GitHub Release.

### Локальная сборка на Linux

Установите Theos для Linux и положите `iPhoneOS9.3.sdk` в `$THEOS/sdks/iPhoneOS9.3.sdk`, затем выполните:

```sh
export THEOS="$HOME/theos"
./build-theos.sh
```

Ручная сборка:

```sh
make clean package PACKAGE_FORMAT=ipa FINALPACKAGE=1
make clean package PACKAGE_FORMAT=deb FINALPACKAGE=1
```

`Makefile` задаёт `TARGET=iphone:clang:9.3:6.0` и `ARCHS=armv7`. SDK 9.3 выбран из-за ограничений Linux Theos toolchain; минимальная версия ОС приложения остаётся 6.0. Не следует путать версию SDK с минимальной версией iOS.

## Альтернативная сборка через Xcode

Сохранены `Slashlib.xcodeproj`, `package-ipa.sh` и `package-deb.sh` для старого Mac/Xcode toolchain. Этот путь требует Xcode/SDK, умеющего линковать ARMv7. Theos/Linux workflow не требует self-hosted Mac runner.

## Текущая функциональность порта

- Пять вкладок: Главная, Поиск, Избранное, Закладки, Аккаунт.
- Поиск SlashLib; MangaLib можно включить в настройках; есть постраничная подгрузка результатов.
- Карточка тайтла, запрос описания и списка глав, сортировка глав.
- Читалка: вертикальная лента, постраничный режим, направление справа налево, сохранение и восстановление позиции.
- Кэширование и декодирование изображений через ImageIO с ограничением одновременной загрузки.
- Фон страниц, светлая/тёмная/автоматическая тема, keep-awake и энергосбережение.
- Избранное, история/последняя позиция чтения, прочитанные главы и ручные закладки в `NSUserDefaults`.
- Загрузка глав в `Documents/SlashlibOffline`; скачанные страницы могут открываться без сети.
- Bearer-токен lib.social в Keychain и проверка `/auth/me`.
- GitHub Gist: поиск/создание приватного Gist и объединение библиотечных данных.

## Ограничения и честный статус

Это перенос в работе, а не подтверждённая 1:1 копия оригинала. В исходном Swift-проекте есть отдельные экраны и подсистемы, которые ещё нужно сравнить и перенести полностью: расширенные параметры читалки, полная авторизация сайта, каталожные фильтры/подборки, расширенная очередь загрузок, диагностика и восстановление. Некоторые API-поля и CDN-хосты требуют проверки на действующем сервисе.

**Сборка через Theos/Linux добавлена, но в среде подготовки архива не запускалась.** Поэтому нельзя утверждать, что workflow уже прошёл компиляцию. Первый запуск GitHub Actions является фактической проверкой; возможные ошибки компиляции/линковки нужно исправить по логу. iOS 6 также может не согласовать TLS с современными HTTPS-серверами, даже если приложение собрано корректно.

IPA не является подписанным сертификатом App Store. Для установки на обычное устройство нужна подходящая подпись/способ sideloading. DEB предназначен для jailbreak-устройств и не устанавливается на stock iOS.
